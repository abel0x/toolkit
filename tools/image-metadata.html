Image Metadata Viewer

Read, edit, sign and remove an image’s EXIF data — camera, date, author and GPS location — losslessly, one image or many.

Drop an image here or click to select

Property Value

Edit metadata

Writes a new EXIF block into a copy of a JPEG or PNG; the picture itself is copied unchanged. Camera details already in the file are kept. Letters such as ç or ş are written as UTF-8, which current tools read; some old programs may show them garbled.

Location

Sign and verify

A signature in the metadata proves that the picture has not changed since you signed it, and that it was signed with your key. It is made with ECDSA P-256 in this browser. Editing or re-saving the picture breaks it; removing the metadata removes it.

No key loaded. A new key is saved as a file; keep it private, like a password.

Remove metadata from several images

JPEG, PNG and WebP files are cleaned the same way, losslessly, and saved together as a ZIP.
