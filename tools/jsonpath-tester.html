JSONPath Tester

Run JSONPath queries (RFC 9535) on your JSON and see the matching values and their paths as you type.

Syntax
$The whole document
.name ['name']A member of an object
[0] [-1]An array element; negative counts from the end
[1:4] [::2]A slice: start, end (not included) and step
* [*]Every member or element
..nameSearches at every depth
[0,2] ['a','b']Several selectors at once
[?@.price < 10]A filter; @ is the item being tested. Operators: == != < <= > >= && || !
[?@.isbn]Items that have the member
length() count() match() search() value()Functions in filters, as defined by RFC 9535

This tool follows RFC 9535, the JSONPath standard. Older tools differ in places (for example, filters there need parentheses). jq is a different, larger language and is not supported.
