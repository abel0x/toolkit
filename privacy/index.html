Privacy

Every tool runs in your browser. Nothing you type, open or generate is sent anywhere.

In short

  • No accounts, no cookies, no analytics, no ads and no tracking.
  • Your input is processed on your device with the browser's own features (Web Crypto, FileReader, Canvas). It is never uploaded.
  • Toolkit keeps a few small preferences in your browser, listed below, and nothing else.

Kept in your browser

These stay on this device, in this browser's storage for the site. Clearing the site's data removes them.

toolkit-language
Your language choice, so English and Turkish pages open in the language you picked.
toolkit-recent-tools-v1
The last tools you opened, shown first in the tool finder (Ctrl/Cmd + K). “Clear recent” in the finder deletes the list.
toolkit-typing-test-settings
The Typing Speed Test's options, such as mode and word list.
toolkit-typing-test-records
Your best Typing Speed Test scores, only if you turn on “Remember personal bests”. The test can delete them.
toolkit-language-redirect
A note for this tab only (session storage) that stops a language redirect from repeating.
Offline copy
The service worker stores the site's own files so the tools work without a connection. It holds no input.

What you give a tool

  • Text and files are read in the browser and stay in the page until you close or reload it.
  • The camera (QR Code Reader) starts only when you press “Scan with camera”, and stops when a code is read, when you press Stop or when you leave the tab. Frames are never stored or sent.
  • The clipboard is written only when you press a Copy button.
  • Share links (“Copy link”) put the tool's input after the # in the address. Browsers do not send that part to a server, but anyone you give the link to can read the input, and chat apps or your browser history may keep it. Do not share secrets this way.

The website host

The site is served by GitHub Pages. Like any web host, GitHub may log standard request details such as your IP address, the page address and your browser's name. The part after # is never among them.

Toolkit does not receive or use these logs; see the GitHub General Privacy Statement.

Links to other sites

Links to GitHub and Buy Me a Coffee open those sites, which have their own privacy policies.
